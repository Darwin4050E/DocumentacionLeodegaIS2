\section{AI Usage Statement}
\label{sec:ai}

The team used Claude (Anthropic) as a support tool for four tasks: generating code, reviewing code, testing code, and formatting this report.
AI output was never accepted as is: each member checked it against the repository, the Sprint Planning document and the client's instructions, and corrected it before using it.
Facts in this report (dates, SHAs, tags, counts and test results) come from Git, GitHub Actions and the tools themselves, not from AI\@.
