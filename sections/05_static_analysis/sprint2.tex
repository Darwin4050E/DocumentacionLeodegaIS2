\subsubsection*{Representative Fixes}

\begin{itemize}[nosep]
  \item \textbf{ESLint} (\sha{16e62e9}): removed unused imports from three test files.
        Allowed the ``unused key in a rest object'' pattern.
        Disabled the fast refresh rule only in \texttt{WizardContext.tsx}, where the context, provider and hook belong together.
        This removed all 8 errors.
  \item \textbf{PHPStan} (\sha{82949ae}): added return types to 67 model relations in 25 models.
        Unknown relation errors went from 38 to 0 and unknown property errors from 155 to 95.
        In total, PHPStan errors went from 225 to 126.
        The commit message reports that the backend suite did not change (1820 passed, 17 skipped).
  \item \textbf{Baseline} (\sha{654eeff}): regenerated the PHPStan baseline. It now lists only the 126 remaining errors.
  \item \textbf{CI} (\sha{2052024}): removed \texttt{continue-on-error} from the ESLint steps in the \texttt{frontend} and \texttt{leodeguita} jobs.
        Before this change, a failing ESLint step did not fail the job.
\end{itemize}

\subsubsection*{Unresolved Issues}

\begin{itemize}[nosep]
  \item \textbf{PHPStan, 126 errors.}
        They are recorded in the baseline, not fixed.
        The five files with most errors hold 72 of them (22, 20, 16, 7 and 7 errors):
        \begin{itemize}[nosep]
          \item \texttt{StoreRoomDetailResource}
          \item \texttt{StoreRoomModerationDetailResource}
          \item \texttt{ReservationsController}
          \item \texttt{OrganizationResource}
          \item \texttt{WalletMovementResource}
        \end{itemize}
        The with-baseline result (0 errors) hides this debt, so both numbers are reported.
        The 4 PHPDoc errors come from \texttt{@SuppressWarnings} annotations written without quotes, and they were not fixed.
  \item \textbf{PHPMD, 39 violations.}
        The pull request did not touch PHPMD, so the result is the same before and after.
        Most are unused parameters, which is also the biggest group in Sprint 1.
        The new ones from Sprint 2 were not reviewed one by one.
  \item \textbf{Pint, 5 files.}
        The pull request did not fix them, so the result is the same before and after.
  \item \textbf{ESLint, 2 warnings.}
        The \texttt{useEffect} hooks in \texttt{PreguntaInicio5} and \texttt{PreguntaInicio6} miss a dependency.
        The commit message says they were left as they are on purpose.
  \item \textbf{Not covered.}
        Pint and PHPMD are not run by the CI, so they depend on manual runs.
\end{itemize}
