\section{Individual Contributions}
\label{sec:contributions}

The project started before the team entered the Software Engineering~II course.
The first meeting of this phase with the client was on 2026-08-31 (C09 in Table~\ref{tab:communications}), and the first commit in the code repository (\sha{8ff13c8}, ``Initial commit: backend Laravel + frontend React'') is from 2026-09-01.
Of the 155 commits that form Sprint~1, 115 were made in September 2026, before the course sprints started on 2026-10-01 (Table~\ref{tab:sprint-plan}).

Because of this early start, the team split into two pairs and each pair implements two sprints.
Darwin Díaz and Geovanny Díaz had already started the implementation, so they took Sprints~1 and~2.
Carla Gutierrez and Joao Dorado will implement Sprints~3 and~4.
For this reason, Carla and Joao have no commits in the code repository (\texttt{Darwin4050E/Leodega}) during Sprints~1 and~2.
During these sprints they worked on the project documents, such as the Sprint Planning document, and wrote most of this report.
They were also in charge of reviewing every flow of the web app and of Leodeguita to point out feedback to the developers.

Commit counts come from \texttt{git shortlog -{}-no-merges} on the code repository.
Sprint~1 is the history up to \sha{ca1799a} (base of \texttt{sprint1-deploy}), and Sprint~2 is the range \sha{ca1799a}..\sha{90dbf81}.
